Music User Token を取る

このページは手元で開いて使います（python3 -m http.server 8000 などローカルサーバー経由）。 取得したトークンはこの画面に出るだけで、どこにも送信されません。

  1. Apple Developer Program の MusicKit キーから作った Developer Token（JWT）を貼る
  2. 「Apple ID で認可」を押して、Apple Music 契約中の Apple ID でサインインする
  3. 出てきた Music User Token を APPLE_MUSIC_USER_TOKEN に入れる

Music User Token の有効期限はおおよそ半年です。切れたらこのページで取り直してください。
